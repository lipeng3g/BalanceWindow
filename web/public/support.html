Frequently asked questions

  • Is Balance Window a bookkeeping app?
    Not quite. It is designed to forecast how planned and recurring income or expenses may change your balance over time. You do not need to record every purchase.
  • Where is my data stored?
    The iOS app stores data locally by default. You can export a JSON backup at any time. Cloud sync is used only after you choose Sign in with Apple.
  • Do I need an account?
    No. You can use the core app locally without signing in. Apple sign-in is optional and enables cloud backup and synchronization.
  • Why can I not create a third account?
    Version 1.0 supports up to two money accounts. Archived accounts also count toward this limit.
  • Can I move data between the web and iOS apps?
    Both apps use a compatible JSON backup format and can import or export independently. Automatic cross-platform sync is not currently provided.
  • What should I do if sign-in or sync fails?
    Your local data remains available. First export a local JSON backup, then check your network and Apple sign-in status. The sync screen will ask you to choose a version whenever local and cloud data conflict.

Report a problem

Open an issue in the Balance Window issue tracker and include the app version, iOS version, device model, steps to reproduce, and the exact error message.

Do not post real financial data, Apple credentials, session cookies, tokens, or private keys.

常见问题

Balance Window 主要用于推演未来现金流趋势，并不是要求记录每笔消费的传统记账软件。iOS 默认将数据保存在本机，无需登录即可使用；Apple 登录仅用于可选的云备份和同步。版本 1.0 最多支持两个资金账户。

如果登录或同步失败，请先导出本机 JSON 备份，再检查网络和 Apple 登录状态。本机与云端数据不一致时，App 会要求你明确选择要保留的版本。
